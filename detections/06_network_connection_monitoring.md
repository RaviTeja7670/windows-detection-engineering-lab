
Detection 06 - Suspicious Network Connection

Status: VALIDATED

Objective

Monitor outbound network connections generated by Windows processes using Sysmon Event ID 3.

Data Source
Index: sysmon
Sourcetype: XmlWinEventLog:Microsoft-Windows-Sysmon/Operational
Event ID: 3 - Network Connection
SPL
index=sysmon sourcetype="XmlWinEventLog:Microsoft-Windows-Sysmon/Operational" EventCode=3
| stats count by host Image SourceIp SourcePort DestinationIp DestinationPort Protocol
| sort - count
Investigation

Review the destination IP, destination port, protocol, source process, and whether the connection is expected.

Validation

A test connection to 1.1.1.1:443 was generated from the monitored Windows VM and observed in Splunk.

False Positives

Browsers, Windows services, update services, security software, and legitimate applications create frequent network connections.

MITRE ATT&CK

Potential mapping: T1071 - Application Layer Protocol, depending on the observed protocol and investigation context.

Alerting

Implemented as WDL - Suspicious Network Connection.

Response

Investigate the destination, process responsible for the connection, DNS activity, and related endpoint events.
